## 👥 User Management Overview

### What is User & Staff Management?
The User & Staff Management module in CREAMS provides comprehensive tools for managing all system users, from creating accounts to tracking professional development. This module ensures proper role assignment, maintains staff directories, and supports performance monitoring across all centres.

### User Categories in CREAMS
The system manages five distinct user categories:

**👑 Administrative Users**
- **System Administrators**: Full system access and configuration
- **Centre Administrators**: Centre-specific administrative control
- **Data Administrators**: Database and reporting oversight

**👥 Operational Staff**
- **Supervisors**: Team leadership and oversight
- **Teachers**: Direct service delivery
- **AJK (Administrative & Support)**: Facility and resource management

**🎓 Service Recipients**
- **Trainees**: Primary service recipients
- **Family Members**: Guardians and family contacts

*[MEDIA SPACE: Organizational chart showing user categories and hierarchy]*

### Role-Based Access Control
User management access varies by role:

**🔐 Admin Access**
- Create, modify, and deactivate all user accounts
- Assign and change user roles
- Manage centre assignments
- Override security restrictions
- Access complete audit trails

**👥 Supervisor Access**
- View staff under supervision
- Update team member information (limited)
- Generate team reports
- Recommend role changes

**🏢 AJK Access**
- View facility-related staff information
- Update contact details (own profile only)
- Access staff scheduling information

**👨‍🏫 Teacher/Staff Access**
- View own profile and team directory
- Update personal contact information
- View reporting relationships

*[MEDIA SPACE: Permission matrix table showing access levels]*

### Key Management Features
- **Centralized user directory**: Complete staff database
- **Role-based security**: Granular permission control
- **Multi-centre support**: Cross-centre staff management
- **Audit tracking**: Complete change history
- **Integration capabilities**: Links with HR and payroll systems

## 🔧 Troubleshooting

### Common User Management Issues

#### Cannot Create New User Account
**Problem**: "Add New User" button not accessible or account creation fails

**Possible Causes and Solutions**:

**Insufficient Permissions**
- **Check admin role**: Only administrators can create accounts
- **Verify permissions**: Confirm user creation permissions
- **Contact system admin**: Request permission elevation

**Duplicate Information**
- **Email already exists**: Use different email address
- **Employee ID conflict**: Assign unique employee identifier
- **Username taken**: Choose alternative username

**System Limitations**
- **User limit reached**: Check system user capacity
- **Centre restrictions**: Verify centre user allocations
- **License limitations**: Confirm system licensing

*[MEDIA SPACE: User creation troubleshooting flowchart]*

#### Staff Profile Information Missing
**Problem**: Profile shows incomplete or outdated information

**Solutions**:
1. **Verify data entry**: Check all required fields completed
2. **Refresh profile**: Reload page to get latest data
3. **Check permissions**: Ensure viewing permissions adequate
4. **Update information**: Add missing data if authorized
5. **Contact administrator**: For persistent data issues

*[MEDIA SPACE: Screenshot of complete vs. incomplete profile examples]*

#### Role Assignment Problems
**Problem**: User cannot access expected features after role change

**Solutions**:
1. **Verify role assignment**: Confirm correct role selected
2. **Check effective date**: Ensure role change is active
3. **Clear browser cache**: Remove stored permission data
4. **Re-login required**: Force fresh permission loading
5. **Permission conflicts**: Review custom permission settings

*[MEDIA SPACE: Role assignment verification checklist]*

### Permission and Access Issues

#### User Cannot Access Modules
**Problem**: Staff member receives "Access Denied" messages

**Common Causes**:
- **Role restrictions**: Role doesn't include module access
- **Centre limitations**: User not assigned to relevant centre
- **Deactivated account**: Account status changed to inactive
- **Permission changes**: Recent permission modifications

**Solutions**:
1. **Review role permissions**: Check module access rights
2. **Verify centre assignment**: Confirm appropriate centre access
3. **Check account status**: Ensure account is active
4. **Update permissions**: Adjust access as needed
5. **Clear session**: Logout and login to refresh permissions

*[MEDIA SPACE: Permission troubleshooting guide]*

#### Directory Search Not Working
**Problem**: Staff directory search returns no results

**Solutions**:
1. **Check search criteria**: Verify spelling and format
2. **Clear filters**: Remove restrictive search filters
3. **Expand search terms**: Use partial names or keywords
4. **Verify permissions**: Ensure directory access permissions
