### 🎨 **Media Production Guidelines**

#### **Screenshot Standards**
```
Resolution: 1920x1080 (Full HD)
Format: PNG for screenshots, JPG for photos
Annotation Style: Consistent callout boxes and arrows
Color Scheme: Match CREAMS system branding
Compression: Optimized for web without quality loss
Naming Convention: MANUAL_SECTION_FEATURE_001.png
```

#### **Video Production Standards**
```
Resolution: 1920x1080 (Full HD)
Frame Rate: 30 FPS minimum
Audio: Clear narration with background music (optional)
Length: 2-5 minutes per video segment
Format: MP4 (H.264 codec)
Captions: SRT files for accessibility
Naming Convention: MANUAL_SECTION_PROCESS_v1.mp4
```

#### **Diagram Design Standards**
```
Format: SVG (scalable) or high-resolution PNG
Color Palette: Consistent with system branding
Typography: Clear, readable fonts (14pt minimum)
Layout: Left-to-right, top-to-bottom flow
Icons: Consistent icon library usage
Export: Multiple formats for different uses
```
