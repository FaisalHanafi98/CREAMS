## 🏗️ System Architecture Foundation

### Authentication & Session Management
CUSTOM MultipleUserGuard implementation:

Session keys: id, role, centre_id, name, email
NOT using Laravel's default auth
Session validation happens in middleware
Role hierarchy: admin > supervisor > teacher > ajk


### Multi-Tenant Data Isolation
CRITICAL: All queries must filter by centre_id

Exception: admin role sees all centres
Every major table includes centre_id field
Use: ->where('centre_id', session('centre_id'))
NEVER expose data across centres

## 🎯 Common Operations Reference

### Fetching Centre-Specific Data
```php
// CORRECT pattern for non-admin users
$trainees = Trainee::where('centre_id', session('centre_id'))
    ->where('enrollment_status', 'active')
    ->get();

// CORRECT pattern for admin users
$trainees = session('role') === 'admin' 
    ? Trainee::all() 
    : Trainee::where('centre_id', session('centre_id'))->get();
