### UATSeeder built

File: `database/seeders/UATSeeder.php`

Design choices (and why):
- **Standalone, not orchestrated.** Existing `DatabaseSeeder` chains nine seeders, two of which contain literal IC numbers (see PDPA findings below). UATSeeder runs alone via `--class=UATSeeder` so the UAT path is fully under PDPA-clean control.
- **Faker default locale.** No `en_MY` locale — produces unmistakably Western-style names so nothing reads like a real Malaysian record.
- **Centre IDs `UA1/UA2/UA3`.** Avoids colliding with the production-style `01/02/03` IDs from `CREAMSSeederFoundationManagement`. Anyone who runs both seeders gets two distinct sets.
- **All emails `@uat.creams.test`.** Visible UAT marker in logs and audit trails.
- **IC numbers built programmatically.** No literal IC pattern in source — generated via `sprintf('%s-%s-%s', $yymmdd, '99', $sequence)` with state code `99` (unused by real Malaysian IC scheme).
- **Idempotent.** Uses `firstOrCreate` keyed on stable identifiers so re-runs don't duplicate.
- **Single shared password.** All 16 staff use `UatPass2026!` — simplifies the recorded walkthrough on Day 5.

Seed counts:
- 3 centres
- 16 staff: 1 super admin + (1 admin + 1 supervisor + 2 teachers + 1 AJK) × 3 centres
- 21 trainees (7 per centre)
- 9 activities (3 per centre)
