CORE FUNCTIONALITY AND ARCHITECTURE
===============================================================================

## System Architecture Overview
CREAMS implements a sophisticated centre-centric multi-tenant architecture designed for Malaysia's rehabilitation center network. The system features custom session-based authentication with hierarchical role-based access control.

## Authentication System (Custom Implementation)
**Multi-Role Authentication**: NOT using Laravel's default Auth system
- Roles: admin, supervisor, teacher, ajk (committee member)
- Custom session management via `MultipleUserGuard.php`
- Session structure includes: id, role, name, centre_id, email, login_time
- IIUM ID integration for university-based authentication
- Role-based dashboard redirection and access control

## Core Modules and Features

### 1. User Management System
- Multi-role user management (admin, supervisor, teacher, ajk)
- Role-specific dashboards with tailored functionality
- Staff profile management with avatar uploads
- IIUM ID validation and integration
- Custom authentication traits and middleware

### 2. Trainee Management System
- Comprehensive trainee profiles with medical conditions
- Progress tracking and attendance management
- Activity enrollment and participation tracking
- Avatar management and profile customization
- Centre-based trainee organization

### 3. Activity & Rehabilitation Management
- Complete activity lifecycle (create, schedule, conduct, track)
- Session-based activity management
- Enrollment system with capacity management
- Real-time attendance marking and progress tracking
- Category-based organization (Physical, Occupational, Speech, Behavioral)
- Weekly schedule views and calendar integration

### 4. Asset Management System
- Comprehensive asset inventory tracking
- Maintenance scheduling (preventive and corrective)
- Asset movement and location tracking
- Multi-centre asset distribution
- Reporting and analytics for asset utilization
- RFID/QR code integration support

### 5. Centre Management
- Multi-centre support with data isolation
- Centre-specific operations and reporting
- Staff and resource allocation by centre
- Centre capacity and operational status tracking

### 6. Communication Systems
- Internal messaging between staff roles
- System-wide notification management
- Public contact form functionality
- Volunteer application system

## Database Architecture
