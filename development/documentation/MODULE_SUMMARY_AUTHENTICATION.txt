EXECUTIVE SUMMARY
================================================================================
The CREAMS authentication module implements a CUSTOM SESSION-BASED authentication
system that completely bypasses Laravel's built-in Auth facade. This system 
provides role-based access control, centre-based data isolation, and custom 
middleware stack for a multi-center rehabilitation management system.

CRITICAL STATUS: WORKING with 2 major issues (password reset broken, mixed auth approaches)

1. CONTROLLERS
================================================================================

1.1 MainController (app/Http/Controllers/MainController.php)
----------------------------------------------------------------
PURPOSE: Primary authentication handler for the entire system
STATUS: ✅ WORKING

KEY METHODS:
- login() - Displays login page with dual identifier support
- check(Request $request) - Processes login with email/IIUM ID support
- registration() - Shows registration page with centre selection
- save(Request $request) - Handles user registration with validation
- logout(Request $request) - Manages logout and session cleanup
- search(Request $request) - Global search functionality

AUTHENTICATION FLOW:
1. Dual Identifier Login: email OR IIUM ID (format: ABCD1234)
2. Password Verification: Hash::check() with secure hashing
3. Session Management: Manual session variables (NOT Laravel Auth)
4. Remember Me: Custom remember token implementation
5. Centre Assignment: Validates centre during registration

SESSION VARIABLES SET:
- session('id') - Current user ID
- session('role') - User role (admin, supervisor, teacher, ajk)
- session('name') - User display name
- session('centre_id') - User's assigned center ID
- session('logged_in') - Authentication flag
- session('login_time') - Login timestamp

SECURITY FEATURES:
- Input validation with custom error messages
- IIUM ID format validation: /^[A-Z]{4}\d{4}$/
- Password complexity: minimum 5 chars, letters + numbers
- Database transaction handling
- Comprehensive logging for audit trails

------------------------------------------------------------------
PURPOSE: Custom authentication check replacing Laravel's default
STATUS: ✅ WORKING

KEY FEATURES:
- Session-based: Checks session('id') and session('role')
- User Verification: Cross-references session with database
- Role Synchronization: Ensures session role matches DB role
